# 石を置ける場所の表示

- 状態: 合意
- Issue: #6（仕様）、#19（実装）、#37（プレースホルダーにした）、#41（計算の実装）
- 関係する決定: [D-0007](../decisions/D-0007-participants-display-and-room-cleanup.md)、[D-0010](../decisions/D-0010-safe-points-on-existing-kyouen.md)、[D-0012](../decisions/D-0012-kyouen-placeholder.md)

## 目的

石を置ける場所を見られるようにする。`vision.md` の共円の基本の機能に当たる。

## 振る舞い

1. 石を置ける場所の表示と非表示を切り替える操作を画面に置く。切り替えは参加者ごとで、ほかの参加者の表示は変わらない。
2. 石を置ける場所は、石のない格子点のうち、そこに石を置いても新しく共円ができない格子点とする。
   すでにできている共円の上の格子点も、置けない場所とする。つまり、3つ以上の石を通る円か直線の上にある格子点は、どれも置ける場所にしない（[D-0010](../decisions/D-0010-safe-points-on-existing-kyouen.md)）。
3. 表示にしているときは、石を置ける場所に印を描く。
4. 盤面が変わったら、石を置ける場所を更新する。石が1個増えた場合は、以前に置けた空き点と追加点を含む候補だけを調べる。以前から置けなかった点は、石を追加しても置けないままとする。追加点自体も候補から外す。
5. 以前の結果がない場合、石の削除、リセット、盤面サイズの変更、undo などで追加以外の変更になった場合は、盤面全体から計算する。石が2個以下なら、石のない格子点はすべて置ける。
6. 円と直線の判定は整数の係数で行い、結果は参加者ごとに保持する。共有する操作の記録には保存しない。計算方法は [D-0014](../decisions/D-0014-kyouen-algorithms.md) にある。

## 受け入れ条件

- [ ] 表示にすると、置いても共円ができない格子点に印が出る
- [ ] 置くと共円ができる格子点には印が出ない
- [ ] すでにできている共円の上の格子点には印が出ない
- [ ] 非表示にすると、印が消える
- [ ] 一人が切り替えても、ほかの参加者の表示は変わらない
- [ ] 計算を単体テストで確かめる
