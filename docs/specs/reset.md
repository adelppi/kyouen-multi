# 盤面のリセット

- 状態: 実装済み
- Issue: #6（仕様）、#16（実装）
- 関係する決定: [D-0007](../decisions/D-0007-participants-display-and-room-cleanup.md)

## 目的

盤面の石をすべて取り除けるようにする。`vision.md` の共円の基本の機能に当たる。

## 振る舞い

1. リセットの操作を画面に置く。
2. リセットを押すと、リセットの操作を記録に追記する。部屋の全員の盤面から石がなくなる。
3. 盤面のサイズは変えない。
4. リセットの前に確かめない。リセットは undo で取り消せる。

## 受け入れ条件

- [ ] リセットを押すと、部屋の全員の盤面から石がなくなる
- [ ] リセットのあとに undo すると、リセットの前の盤面に戻る
