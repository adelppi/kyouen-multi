# 操作の履歴

- 状態: 下書き
- Issue: #6（仕様）、#14（実装）
- 関係する決定: [D-0004](../decisions/D-0004-tech-stack.md)

## 目的

誰がどの操作をしたかを分かるようにする。`vision.md` の「履歴から、誰が石を置いたかを知ることができる」に当たる。

## 振る舞い

1. 操作の記録を、新しい順に一覧で表示する。
2. 一覧の1行に、操作した参加者の名前と色、操作の種類、格子点（置くと取り除くのとき）を表示する。
3. 何もしない操作になったものと、undo で取り消されている操作は、ほかの行と見分けられる見た目にする。
4. 一覧の行にポインタを重ねると、その操作の格子点を盤面で強調する。

## 受け入れ条件

- [ ] 石を置くと、置いた人の名前が一覧の先頭に出る
- [ ] 一覧の行から、盤面のどの石の操作かが分かる
- [ ] undo で取り消された操作が、ほかの行と見分けられる

## 範囲外

- 過去の盤面に戻して見る機能
