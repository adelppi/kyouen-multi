# 盤面と石の操作

- 状態: 下書き
- Issue: #6（仕様）、#12（実装）
- 関係する決定: [D-0004](../decisions/D-0004-tech-stack.md)

## 目的

盤面を表示し、石を置いたり取り除いたりできるようにする。`vision.md` の共円の基本の機能に当たる。

## 振る舞い

1. 正方形の格子の盤面を SVG で表示する。
2. 石のない格子点を押すと、その格子点に石を置く操作を記録に追記する。
3. 石のある格子点を押すと、その石を取り除く操作を記録に追記する。どの参加者が置いた石でも取り除ける。
4. 盤面は、[操作の記録](operation-log.md)から計算した結果を表示する。
5. 石の色は1色にする。

## 受け入れ条件

- [ ] 石のない格子点を押すと石が置かれる
- [ ] 石のある格子点を押すと石が取り除かれる
- [ ] ほかの参加者の操作がすぐに盤面に出る
- [ ] スマートフォンの画面でも格子点を押し分けられる

## 範囲外

- 手番の管理（`vision.md` の「やらないこと」）
- 盤面のサイズの切り替え（`board-size.md`）
