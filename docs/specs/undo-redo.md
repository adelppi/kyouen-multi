# 全体の undo と redo

- 状態: 合意
- Issue: #6（仕様）、#13（実装）
- 関係する決定: [D-0004](../decisions/D-0004-tech-stack.md)

## 目的

参加者全体の操作に対して undo と redo が働くようにする。`vision.md` のマルチプレイの管理に当たる。

## 振る舞い

1. undo と redo の操作を画面に置く。どの参加者が押しても、記録に undo か redo の操作を追記する。
2. undo と redo の結果は、記録を先頭から順に当てはめて決める。当てはめ方は次のとおり。
   - 置く、取り除く、リセット、サイズ変更のうち、盤面を変えたものを「取り消せる操作」の列に積む。このとき「やり直せる操作」の列を空にする。
   - undo は、「取り消せる操作」の列の最後の操作を取り消し、「やり直せる操作」の列に積む。列が空なら何もしない。
   - redo は、「やり直せる操作」の列の最後の操作をもう一度当てはめ、「取り消せる操作」の列に戻す。列が空なら何もしない。
3. undo は、誰の操作でも取り消す。押した人の操作だけを取り消すのではない。
4. 2人がほぼ同時に undo を押したら、2つの操作が取り消される。
5. 取り消せる操作がないときは undo を、やり直せる操作がないときは redo を、押せない見た目にする。
6. キーボードでは、Ctrl+Z（Mac は Cmd+Z）で undo、Ctrl+Shift+Z（Mac は Cmd+Shift+Z）で redo とする。

## 受け入れ条件

- [ ] Aさんが置いた石を、Bさんの undo で取り消せる
- [ ] undo のあとに redo すると、元の盤面に戻る
- [ ] undo のあとに誰かが石を置くと、redo できなくなる
- [ ] 2人がほぼ同時に undo を押すと、2つの操作が取り消され、両方の盤面が同じになる
- [ ] 上の当てはめ方を単体テストで確かめる

## 範囲外

- 一人の操作だけを取り消す undo
