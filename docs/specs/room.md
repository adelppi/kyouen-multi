# 部屋と参加

- 状態: 下書き
- Issue: #6（仕様）、#11（実装）
- 関係する決定: [D-0003](../decisions/D-0003-room-and-participants.md)、[D-0005](../decisions/D-0005-room-lifetime-and-board-size.md)

## 目的

複数人が同じ盤面に集まれるようにする。`vision.md` の「複数人が参加できる」に当たる。

## 振る舞い

1. アプリのトップの URL を開くと、新しい部屋が作られ、その部屋の URL に移る。
2. 部屋の URL を開いた人は、その部屋に入る。部屋がまだなければ、その URL で新しく作る。
3. 部屋に入るとき、名前を入れる。同じブラウザで次に入るときは、前に入れた名前を初めから入れておく。
4. 部屋にいる参加者の名前と色を、画面に一覧で表示する。参加者が入ったり出たりしたら、一覧をすぐに更新する。
5. 部屋の URL をコピーする操作を画面に置く。
6. 部屋の参加者が全員抜けたら、部屋と操作の記録を消す。そのあとで同じ URL を開いた人は、新しい部屋に入る（[D-0005](../decisions/D-0005-room-lifetime-and-board-size.md)）。

## 受け入れ条件

- [ ] トップの URL を開くと、新しい部屋の URL に移る
- [ ] 部屋の URL を別のブラウザで開くと、同じ部屋に入る
- [ ] 名前を入れないと部屋に入れない
- [ ] 参加者の一覧に、部屋にいる全員の名前が出る
- [ ] 参加者が出ると、一覧から消える
- [ ] 全員が抜けたあとで同じ URL を開くと、石のない新しい部屋に入る

## 範囲外

- 認証と招待（`vision.md` の「やらないこと」）
