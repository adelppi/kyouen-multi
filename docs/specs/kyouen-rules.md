# 共円のルールと用語

## 目的

共円のルールと用語を1か所にまとめる。ほかの仕様は、ここで定義した用語を使う。

このアプリでルールの進行や勝ち負けをどこまで扱うかは、この文書では決めない。`vision.md` と機能ごとの仕様で決める。

## 出典

- [共円という数学ゲームのルールと定石（高校数学の美しい物語）](https://manabitimes.jp/math/1034)
- [共円 / Kyouen（yambi.jp）](https://yambi.jp/kyouen/)。一人で遊ぶ版。説明は「find four concyclic stones」だけで、盤面の大きさの切り替え、リセット、取り消しとやり直し、結果の表示、ヒントの機能がある

## ルール

出典の記事に書かれているルールを写す。

- 盤面は正方形の格子を使う。大きさは 10×10 くらいが勧められている。
- 石は一色でよい。
- 2人以上なら何人でも遊べる。
- プレーヤーは1人ずつ順番に、格子点に石を置く。
- 同じ円周の上に4つ以上の石がある状態を作らないように置く。この状態を共円という。
- 直線は半径が無限大の円とみなす。同じ直線の上に4つの石を置いても共円になる。
- 共円を作ったことをほかのプレーヤーに指摘されると、そのプレーヤーの負けで、ゲームから抜ける。
- 共円ができても、指摘されないまま次の石が置かれると、その共円はセーフになる。
- 最後に残ったプレーヤーが勝ちになる。

## 用語

| 用語 | 意味 |
|---|---|
| 格子点 | 盤面の格子の交点。石を置ける場所 |
| 石 | 格子点に置くもの。色の区別はない |
| 共円 | 同じ円周（直線を含む）の上に4つ以上の石がある状態。また、その円や直線 |
| 指摘 | 共円ができたことを、ほかのプレーヤーが告げること |
| セーフ | 共円ができても、指摘されないまま次の石が置かれたこと |
| 定石 | よく現れる共円の形。出典では、長方形、等脚台形、八角形定石、六角形定石、十二角形定石が紹介されている |

## 判定の方法

4つの格子点 (x1, y1) 〜 (x4, y4) が同じ円周の上か同じ直線の上にあるのは、次の行列式が 0 になるときに限る。

```text
| x1²+y1²  x1  y1  1 |
| x2²+y2²  x2  y2  1 |
| x3²+y3²  x3  y3  1 |
| x4²+y4²  x4  y4  1 |
```

格子点の座標は整数なので、整数だけで計算でき、誤差が出ない。

## 範囲外

- 正三角形の格子で遊ぶダイヤモンド共円や、縦横比 1:√2 の格子で遊ぶ共円など、出典にある派生のルール
- 一人で遊ぶ詰め共円
