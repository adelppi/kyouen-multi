# 盤面の画像の保存

- 状態: 実装済み
- Issue: #49
- 関係する決定: [D-0017](../decisions/D-0017-board-image.md)

## 目的

参加者が、いまの盤面を画像として保存できるようにする。`vision.md` の共円の基本の機能に当たる。

## 振る舞い

1. 盤面を画像で保存するボタンを画面に置く。押すと、その時点の盤面を PNG の画像にして、`kyouen.png` という名前でダウンロードする。
2. 画像には、背景、格子、石を描く。完成した円と直線は、[完成した円の表示](kyouen-display.md)を表示にしているときだけ描く。
3. 石を置ける場所の印、履歴の強調、石を置く前の予告、ほかの参加者のカーソルは描かない。盤面の外に文字も描かない。
4. 色は、画面のテーマにかかわらず明るいテーマの色にする。
5. 盤面のまわりの余白、石の大きさ、線の太さは画面の盤面と同じにする。画像の幅と高さは、盤面のサイズにかかわらず 1200 ピクセルにする。
6. 画像は参加者のブラウザの中で作り、サーバーや操作の記録には送らない。

## 受け入れ条件

- [ ] ボタンを押すと、盤面の PNG の画像がダウンロードされる
- [ ] 画像に背景、格子、石が描かれる
- [ ] 完成した円の表示を表示にしているときだけ、円と直線が描かれる
- [ ] 置ける場所の印とカーソルは描かれない
- [ ] 暗いテーマで保存しても、明るいテーマの色で描かれる
- [ ] 画像の元になる SVG を作る処理を単体テストで確かめる

## 範囲外

- 画像を外部のサービスに送ったり、共有したりすること
- PNG 以外の形式で保存すること
