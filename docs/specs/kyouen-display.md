# 完成した円の表示

- 状態: 実装済み
- Issue: #6（仕様）、#18（実装）、#37（プレースホルダーにした）、#41（判定の実装）、#47（全員で共通にした）
- 関係する決定: [D-0007](../decisions/D-0007-participants-display-and-room-cleanup.md)、[D-0012](../decisions/D-0012-kyouen-placeholder.md)、[D-0014](../decisions/D-0014-kyouen-algorithms.md)、[D-0016](../decisions/D-0016-shared-display-toggles.md)

## 目的

盤面にできている共円を見られるようにする。`vision.md` の共円の基本の機能に当たる。

## 振る舞い

1. 完成した円の表示と非表示を切り替える操作を画面に置く。切り替えは部屋の全員で共通で、一人が切り替えると、ほかの参加者の表示も同じになる（[D-0016](../decisions/D-0016-shared-display-toggles.md)）。
   切り替えの状態は Liveblocks の Storage に、操作の記録とは別に置く。操作の記録と履歴には入れず、undo と redo の対象にしない。部屋を作ったときは非表示にする。
2. 表示にしているときは、4つ以上の石を通る円と直線をすべて盤面に描く。
3. 共円かどうかは各クライアントが計算する。3点の外心を求める式を整数の係数で扱い、[共円のルールと用語](kyouen-rules.md)の行列式と同じ結果になるように判定する。一直線の点も扱う。計算方法は [D-0014](../decisions/D-0014-kyouen-algorithms.md) にある。
4. 盤面が変わったら、描く円と直線を更新する。石が1個増えた場合は、その点を含む候補だけを調べ、以前の結果に加える。以前の結果がない場合、石の削除、リセット、undo などで追加以外の変更になった場合は、盤面全体から計算する。
5. 同じ円や直線は1つにまとめ、その上の石をすべて結果に含める。計算結果は参加者ごとに保持し、共有する操作の記録には保存しない。
6. 円と直線は、明るいテーマと暗いテーマの両方で、盤面の背景に対して3:1以上のコントラストで描く。

## 受け入れ条件

- [x] 4つの石が同じ円の上にあると、その円が描かれる
- [x] 4つの石が同じ直線の上にあると、その直線が描かれる
- [x] 非表示にすると、円と直線が消える
- [ ] 一人が切り替えると、ほかの参加者の表示も切り替わる
- [ ] あとから部屋に入った参加者にも、同じ表示が出る
- [ ] 切り替えが履歴に出ず、undo と redo で戻らない
- [x] 判定を単体テストで確かめる

## 範囲外

- 共円を作った参加者の指摘や負けの判定（`vision.md` の「やらないこと」）
