# 完成した円の表示

- 状態: 下書き
- Issue: #6（仕様）、#18（実装）
- 関係する決定: なし

## 目的

盤面にできている共円を見られるようにする。`vision.md` の共円の基本の機能に当たる。

## 振る舞い

1. 完成した円の表示と非表示を切り替える操作を画面に置く。
2. 表示にしているときは、4つ以上の石を通る円と直線をすべて盤面に描く。
3. 共円かどうかは、[共円のルールと用語](kyouen-rules.md)の判定の方法で、各クライアントが計算する。
4. 盤面が変わったら、描く円と直線を計算し直す。

## 受け入れ条件

- [ ] 4つの石が同じ円の上にあると、その円が描かれる
- [ ] 4つの石が同じ直線の上にあると、その直線が描かれる
- [ ] 非表示にすると、円と直線が消える
- [ ] 判定を単体テストで確かめる

## 範囲外

- 共円を作った参加者の指摘や負けの判定（`vision.md` の「やらないこと」）
