# 盤面のサイズの切り替え

- 状態: 合意
- Issue: #6（仕様）、#17（実装）
- 関係する決定: [D-0005](../decisions/D-0005-room-lifetime-and-board-size.md)、[D-0009](../decisions/D-0009-selectable-board-sizes.md)

## 目的

盤面のサイズを切り替えられるようにする。`vision.md` の共円の基本の機能に当たる。

## 振る舞い

1. 盤面のサイズを選ぶ操作を画面に置く。選べるサイズは、5×5 から 20×20 までの16通りとする（[D-0009](../decisions/D-0009-selectable-board-sizes.md)）。
2. サイズを選ぶと、サイズ変更の操作を記録に追記する。部屋の全員の盤面のサイズが変わり、置いてある石はすべて取り除かれる。
3. 部屋を作ったときのサイズは 9×9（格子点が縦横に9つずつ）とする。
4. サイズ変更は undo で取り消せる。取り消すと、変える前のサイズと石に戻る。
5. 選べるサイズの外のサイズを指定したサイズ変更と、石がない盤面で今と同じサイズを指定したサイズ変更は、盤面が変わらないので、何もしない操作として扱う。

## 受け入れ条件

- [ ] サイズを選ぶと、部屋の全員の盤面のサイズが変わり、石がなくなる
- [ ] 部屋を作ったときの盤面が 9×9 になっている
- [ ] 5×5 から 20×20 までのサイズを選べる
- [ ] サイズ変更のあとに undo すると、変える前のサイズと石に戻る

## 範囲外

- 正方形でない盤面

## 未解決の項目
