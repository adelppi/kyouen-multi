# カーソルと軌跡

- 状態: 下書き
- Issue: #6（仕様）、#15（実装）
- 関係する決定: [D-0004](../decisions/D-0004-tech-stack.md)

## 目的

ほかの参加者がどこを見ているかを分かるようにする。`vision.md` の「参加者のカーソルの軌跡を、リアルタイムに画面に表示する」に当たる。

## 振る舞い

1. ほかの参加者のカーソルを、その参加者の色と名前で盤面の上に表示する。自分のカーソルは表示しない。
2. カーソルの位置は Liveblocks の Presence で送る。記録には入れない。
3. 位置は画面の座標ではなく盤面の座標で送る。画面の大きさが違っても、同じ格子点の上に表示される。
4. 送る間隔は 50ms ごとくらいに間引き、受け取った側で位置を補間して滑らかに動かす。
5. 直近の位置をつないだ線を軌跡として描き、古い部分から薄くして消す。
6. カーソルが盤面の外に出たら、そのカーソルを隠す。

## 受け入れ条件

- [ ] ほかの参加者のカーソルが、名前と色つきで表示される
- [ ] カーソルの後ろに軌跡が表示され、少しずつ消える
- [ ] 画面の大きさが違うブラウザどうしで、カーソルが同じ格子点の上に表示される
- [ ] カーソルが盤面の外に出ると隠れる

## 範囲外

- タッチ操作の位置の共有
