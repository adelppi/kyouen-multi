# 要求と思想

共円マルチが誰のためのアプリで、何をして何をしないのかを書く。機能を足すかどうか迷ったときは、この文書に照らして決める。

この文書を書き換えるときは、理由を `decisions/` に残す。まだ決まっていない項目は「未記入」とし、`open-questions.md` の項目へリンクする。最初の内容を決めた理由は [D-0002](decisions/D-0002-vision.md) にある。

## 誰のためのアプリか

[共円](specs/kyouen-rules.md)というボードゲームを、複数人で遊びたい人のためのアプリ。

## 解決したいこと

共円を複数人で遊べるようにする。複数人でプレイしたときに、不自由がなく、シンプルで洗練された体験を提供する。

## 責務

このアプリが受け持つ範囲を書く。

- 共円の盤面を参加者で共有し、操作を同期する。
- マルチプレイを管理する。参加者、カーソル、操作の履歴、取り消しとやり直し、同時の操作の競合を扱う。

## やること

### 共円の基本の機能

- ボードに石を置く、取り除く。
- 完成した円の表示と非表示を切り替える。
- 石を置くことのできる場所の表示と非表示を切り替える。
- 盤面のサイズを切り替える。
- 盤面をリセットする。
- 取り消し（undo）とやり直し（redo）。

### マルチプレイの管理

基本の機能より、こちらを重視する。

- 複数人が参加できる。
- 参加者のカーソルの軌跡を、リアルタイムに画面に表示する。
- 取り消しとやり直しは一人の操作ではなく、参加者全体の操作に対して働く。
- 履歴から、誰が石を置いたかを知ることができる。
- 同時の操作の競合を解決する。

## やらないこと

このアプリが面倒をみないことを書く。ここに書いたことを求める Issue は、この文書を書き換える合意がない限り受けない。

- ルールの進行。手番の管理、共円の指摘、離脱、勝ち負けの判定はしない。
- 認証。参加者はログインしない。
- 招待。部屋の URL を共有すれば参加できる。部屋の詳しい決まりは [D-0003](decisions/D-0003-room-and-participants.md) にある。

## 判断の基準

機能の取捨や設計で迷ったときに優先する考え方を、優先する順に書く。

1. 複数人でプレイしたときの体験。不自由がなく、シンプルで洗練されていることを、ほかのすべてより優先する。
2. マルチプレイの管理。
3. 共円の基本の機能。
4. ルールの進行や勝敗の管理。このアプリでは重要ではない。
