# D-0017 盤面を画像として保存する

- 日付: 2026-10-19
- 決めた人: adelppi
- 関係する Issue と PR: #49
- 解決した未解決の項目: なし
- 置き換える記録: なし

## 背景

adelppi から、盤面の写真を撮れるようにしたいと依頼があった。`vision.md` の「やること」にない機能なので、書き足す必要があった。画像に何を描くかも決める必要があった。

## 決定

- 盤面を画像として保存する機能を、`vision.md` の共円の基本の機能に加える。
- 画像には背景、格子、石を描く。完成した円と直線は、完成した円の表示を表示にしているときだけ描く。
- 石を置ける場所の印、履歴の強調、石を置く前の予告、ほかの参加者のカーソル、盤面の外の文字は描かない。
- 色は明るいテーマに固定する。
- 保存の形式は PNG、ファイル名は `kyouen.png`、画像の幅と高さは 1200 ピクセルにする。画像はブラウザの中で作る。

## ほかの選択肢

- 石を置ける場所の印も描く案。遊んでいる最中の手がかりで、残す盤面には要らないので採らなかった。
- 完成した円と直線を、表示の切り替えにかかわらず描く案。画面に見えていない線が画像に出るので採らなかった。
- 撮った人の画面のテーマに合わせる案。送った相手の環境で見え方が変わるので採らなかった。
- 日時や部屋の名前、石の数を盤面の外に書く案。`vision.md` の「シンプル」に合わせて採らなかった。
- 画像をクリップボードにコピーする案、SVG のまま保存する案。まず PNG のダウンロードだけにした。

## 根拠

- 描くものは、Claude が「状態を表す層だけを入れ、操作中の一時的な表示を外す」案を示し、adelppi が「背景と格子と線と石だけ」と答えて決まった。
- 円と直線を表示の切り替えに合わせることと、明るいテーマに固定することは、Claude が推奨し、adelppi が「そうしよう」と答えて決まった。
- PNG、ファイル名、1200 ピクセル、ブラウザの中で作ることは Claude が決めた。

## 影響

- `vision.md` に書き足した。
- `specs/board-image.md` を新しく書いた。
