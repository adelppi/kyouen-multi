# D-0011 カーソルの軌跡を表示しない

- 日付: 2026-10-19
- 決めた人: adelppi
- 関係する Issue と PR: #35、#36
- 解決した未解決の項目: なし
- 置き換える記録: なし

## 背景

#15 で、ほかの参加者のカーソルの後ろに、直近の位置をつないだ線を軌跡として描いた。実装を見た adelppi から、カーソルを小さくし、軌跡も消すように求められた。

## 決定

- ほかの参加者のカーソルの軌跡は表示しない。カーソルの位置を補間して滑らかに動かすことは続ける。
- `vision.md` の「参加者のカーソルの軌跡を、リアルタイムに画面に表示する」を、カーソルを表示し、軌跡は表示しないと書き換える。

## ほかの選択肢

- 軌跡を残す案。adelppi の求めにより採らなかった。

## 根拠

adelppi の「軌跡も消して」という指示による。

## 影響

- `vision.md` の「やること」を書き換えた。
- `specs/cursors.md` から軌跡の振る舞いと受け入れ条件を外し、範囲外に移した。
