# D-0007 参加者の色、表示の切り替え、部屋を消すまでの待ち時間

- 日付: 2026-10-18
- 決めた人: adelppi
- 関係する Issue と PR: #24
- 解決した未解決の項目: OQ-007、OQ-009、OQ-012、OQ-013、OQ-014
- 置き換える記録: なし

## 背景

実装の Issue（#11〜#19）に入る前に、仕様の下書きに残った未解決の項目を決める必要があった。D-0005 で決めた「9×9」の意味と、全員が抜けたら部屋を消すことの細かい扱いも確かめる必要があった。

## 決定

- 参加者の色は、部屋に入った順に、決めた色の並びから割り当てる。同じ名前の参加者がいてもよく、色で見分ける（OQ-007）。
- 石は1色のままにし、石ごとに置いた参加者は履歴の一覧で分かるようにする（OQ-009）。
- リセットの前に確かめない。undo で戻せるため（OQ-012）。
- 完成した円の表示と、石を置ける場所の表示は、参加者ごとに切り替える（OQ-013）。
- 石を置ける場所は、石のない格子点のうち、置いても新しく共円ができない格子点とする（OQ-014）。
- 9×9 は、格子点が縦横に9つずつ並ぶ盤面とする。D-0005 の解釈のとおり。
- 部屋の参加者が全員抜けたら、5分待ってから部屋と記録を消す。5分のうちに誰かが入れば消さない。

## ほかの選択肢

- 参加者が色を選ぶ案、同じ名前を許さない案（OQ-007）
- 石にポインタを重ねると置いた人の名前を出す案、石を置いた人の色で塗る案（OQ-009）
- リセットの前に確かめる案（OQ-012）
- 表示の切り替えを部屋の全員で共通にする案（OQ-013）
- 石のない格子点すべてを置ける場所とする案（OQ-014）
- 全員が抜けたらすぐに部屋を消す案。一人で遊んでいる人がページを再読み込みしたときに、盤面が消えるおそれがあるので採らなかった。

## 根拠

- Claude が推奨の案を示し、adelppi が「その通りにしてください」と答えて決まった。
- 待ち時間は、Claude が「数分」と示し、adelppi が受け入れた。5分という値は Claude が決めた。
