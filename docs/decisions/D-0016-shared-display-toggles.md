# D-0016 表示の切り替えを部屋の全員で共通にする

- 日付: 2026-10-19
- 決めた人: adelppi
- 関係する Issue と PR: #47
- 解決した未解決の項目: なし
- 置き換える記録: [D-0007](D-0007-participants-display-and-room-cleanup.md) の、表示を参加者ごとに切り替える決定（OQ-013）

## 背景

D-0007 では、完成した円の表示と石を置ける場所の表示を、参加者ごとに切り替えると決めた。実装もそのとおりで、一人が切り替えても、ほかの参加者の表示は変わらなかった。adelppi から、この2つの切り替えを部屋で同期したいと依頼があった。

## 決定

- 完成した円の表示と、石を置ける場所の表示は、部屋の全員で共通にする。一人が切り替えると、ほかの参加者の表示も同じになる。
- 切り替えの状態は Liveblocks の Storage に、操作の記録とは別に置く。部屋が消えるまで残り、あとから部屋に入った参加者にも同じ表示が出る。
- 切り替えは操作の記録と履歴に入れず、undo と redo の対象にしない。
- 部屋を作ったときは、どちらも非表示にする。

## ほかの選択肢

- 参加者ごとのままにする案。依頼に合わないので採らなかった。
- 切り替えを操作の記録に入れる案。undo で表示が切り替わり、履歴に盤面と関係のない行が並ぶので採らなかった。
- 切り替えを Presence で送る案。Presence は参加者ごとの値なので、部屋で1つの値を決めるには別の決まりが要る。あとから入った参加者に値を伝えることもできないので採らなかった。

## 根拠

- 部屋で共通にすることは、adelppi が「同期するようにしたい」と依頼して決まった。
- Storage に置くこと、記録に入れないこと、初期値を非表示にすることは Claude が決めた。
