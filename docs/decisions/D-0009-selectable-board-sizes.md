# D-0009 選べる盤面のサイズ

- 日付: 2026-10-19

- 関係する Issue と PR: #17
- 解決した未解決の項目: OQ-015

## 背景

盤面のサイズの切り替え（#17）を実装するにあたり、選べるサイズが決まっていなかった。部屋を作ったときのサイズは 9×9 と決まっている（D-0005）。

## 決定

- 選べるサイズは、5×5 から 20×20 までの16通りとする。どれも、格子点が縦横に同じ数だけ並ぶ盤面とする。

## ほかの選択肢

- 6×6 から 15×15 までの10通り。Claude が推奨した案で、9×9 と出典の 10×10 を含む。
- 6×6、9×9、12×12、15×15 の4通り。

## 根拠

Claude が3つの案を示し、adelppi が「5×5〜20×20 の全部」を選んだ。

## 影響

- `specs/board-size.md` に、選べるサイズを書いた。
- `open-questions.md` の OQ-015 を解決済みにした。
