# D-0010 できている共円の上の格子点の扱い

- 日付: 2026-10-19
- 決めた人: adelppi
- 関係する Issue と PR: #19
- 解決した未解決の項目: OQ-016
- 置き換える記録: なし

## 背景

石を置ける場所の表示（#19）を実装するにあたり、すでに4つ以上の石が通っている円や直線（できている共円）の上の格子点を、置ける場所にするかが決まっていなかった。D-0007 では、置ける場所を「置いても新しく共円ができない格子点」としている。

## 決定

- すでにできている共円の上の格子点も、置けない場所にする。石のない格子点のうち、3つ以上の石を通る円か直線の上にあるものは、すべて置けない場所とする。

## ほかの選択肢

- 置ける場所にする案。すでにある共円に石が増えるだけなので、新しい共円とはみなさない。

## 根拠

Claude が2つの案を示し、adelppi が推奨の「置けない場所にする」を選んだ。
