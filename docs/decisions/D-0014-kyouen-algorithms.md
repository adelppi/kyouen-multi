# D-0014 外心を使って共円と置ける場所を計算する

## 背景

担当者から、4点の組合せを調べ、最初の3点の外心からの距離で共円を判定する案が示された。外心は2本の垂直二等分線の交点から求める。石の追加時は、追加点を含む候補だけを調べる。置ける場所も、空き点ごとに追加点を含む候補を調べる方針とした。

最大の20×20に400個の石がある場合、4点組の全列挙は1,050,739,900通りになる。外心の考え方を保ち、同じ円や直線になる3点組をまとめて判定の回数と作業用のメモリを減らす。

## 決定

- 2本の垂直二等分線を連立した式から、円の整数係数 `a(x²+y²)+bx+cy+d=0` を求める。3点が一直線なら `a=0` の直線を求める。最大公約数と符号で係数をそろえ、同じ円や直線を同じキーにする。
- 固定した2点と、ほかの1点から求めた係数をまとめる。同じ係数になる別の1点があれば4点が共円になる。結果の石は集合として統合し、5個以上の石も漏らさない。4点組をすべて配列に保存しない。
- 石の追加時は追加点と以前の石1個を固定し、ほかの石から求めた係数をまとめる。以前の共円は残し、同じ円や直線が見つかったらその上の石を加える。
- 置ける場所の全計算では、空き点と石1個を固定し、ほかの石の係数が重複するかを調べる。追加時は空き点と追加点を固定し、以前の石2個が同じ係数になるかを調べる。危険だと分かった空き点は、その時点で調査を終える。
- 表示ごとに直前の盤面と結果を保持する。追加以外の変更や、初めて計算する盤面は全計算に戻す。盤面の差を調べるので、ほかの参加者の操作や複数の変更をまとめて受け取った場合にも対応する。
- `findKyouen` と `findSafePoints` の既存の引数と返り値は保つ。盤面の表示では、参加者ごとに作る計算器を使う。追加ライブラリは導入しない。

## 検証

円、直線、非共円、同じ曲線上の5点以上、入力順、計算誤差を単体テストで確かめる。追加、削除、undo 相当の盤面復元、サイズ変更を含む結果を、独立した4点の行列式による判定と照合する。最大盤面の計算時間も測る。

## ほかの選択肢

4点組を全列挙する案は、担当者の最初の案。最大盤面の計算量とメモリ使用量を減らすため、同じ円や直線になる候補をまとめる。

## 影響

`lib/kyouen.ts`、判定のテスト、盤面の表示からの呼び出しを変更する。マルチプレイの保存形式と画面の操作は変えない。
