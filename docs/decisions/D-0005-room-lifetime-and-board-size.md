# D-0005 部屋を残す期間と、盤面のサイズ

- 日付: 2026-10-18
- 決めた人: adelppi
- 関係する Issue と PR: #21
- 解決した未解決の項目: OQ-008、OQ-010、OQ-011
- 置き換える記録: なし

## 背景

仕様の下書き（#6）で、部屋と記録をいつまで残すか、盤面のサイズ、サイズを変えたときの石の扱いが決まっていなかった。

## 決定

- 部屋と操作の記録は、部屋の参加者が全員抜けるまで残す。全員が抜けたら消す。
- 部屋を作ったときの盤面のサイズは 9×9 にする。9×9 は、格子点が縦横に9つずつ並ぶ盤面とする。
- 盤面のサイズを変えたら、置いてある石をすべて取り除く。

## ほかの選択肢

- 部屋と記録を期限を決めずに残す案と、最後の操作から一定の期間が過ぎたら消す案。adelppi が「全員が抜けるまで」を選んだ。
- サイズを変えたときに、新しい盤面に入る石だけを残す案。adelppi が「リセット」を選んだ。

## 根拠

adelppi の答えによる。9×9 を格子点の数とするのは Claude の解釈で、adelppi に確かめる。

## 影響

- `specs/room.md` と `specs/operation-log.md` に、全員が抜けたら部屋と記録を消すことを書いた。
- `specs/board-size.md` と `specs/operation-log.md` に、部屋を作ったときのサイズと、サイズ変更で石を取り除くことを書いた。
- 選べるサイズは決まっていないので、OQ-015 に起票した。
